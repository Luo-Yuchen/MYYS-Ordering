# 馒有意思 · 微信小程序本地体验版

这是一套独立于原网页项目的微信原生小程序。它不会修改或替换原来的 React 网站。

## 已包含功能

- 顾客端：浏览商品、分类筛选、购物车、到店自取/邻里配送、提交预约、查看订单状态。
- 商家端：查看订单、修改订单状态、查看备货汇总、商品新增与修改、上下架、库存管理。
- 店铺装修：修改店铺标记、名称、说明、首页文案、按钮、配送提示和背景图片。
- 本地图片：可从相册或相机选择商品图、首页背景图，并保存到当前小程序设备。
- 本地数据：商品、购物车、订单和店铺设置均保存在微信小程序本地存储。

## 本地运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹 `wechat-mini-program`。
4. AppID 可先使用测试号；项目配置内预置了 `touristappid`，如开发者工具要求，可替换为你自己的小程序 AppID。
5. 导入后点击“编译”，首页即为顾客端，右上角可切换到商家端。

## 体验建议

1. 在顾客端选择商品并提交一笔预约订单。
2. 打开商家端，在“订单”中修改为“制作中”或“待取货”。
3. 返回顾客端，在“订单”中查看同步后的状态。
4. 在商家端下架商品、编辑商品或修改店铺装修，再返回顾客端查看效果。

## 当前限制

- 数据只在当前设备和当前开发者工具环境中共享，不同手机之间不会同步。
- 这是体验版，不会发起真实支付、配送或订单通知。
- 清除微信开发者工具缓存、删除小程序或点击“恢复全部演示数据”会丢失本地体验数据。
- 正式上线时需要把商品、订单、图片和商家权限迁移到云数据库与云存储。
